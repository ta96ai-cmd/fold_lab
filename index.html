Use it

PDF: spot colours CutContour & Crease, one layer per kind. DXF: layers CUT, CREASE, BLEED, SAFE, DIMENSIONS, LABELS, in mm. To design artwork, use the PDF page: artwork exported at that page size lines up in 3D.

Sheet layout

Allowances: panel = inside size + board; lid depth = W + board. These are standard starting values for proofs. Check the first physical sample with your die-maker before cutting a die.
